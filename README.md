# 🍽️ Food Ordering Website

This project is a full-fledged food ordering platform developed as part of my internship at **Vilearnx Advanced Technologies**.  
The website allows users to browse and order food from a dynamic menu, featuring **user authentication**, an intuitive **shopping cart**, and robust **admin functionalities**.  
Built using the **MERN stack** (MongoDB, Express.js, React.js, Node.js), it offers a seamless and efficient user experience.

---

## 🚀 Features

### 1️⃣ User Authentication
- **Signup/Login** – Secure registration and login using **JWT (JSON Web Tokens)**.  
- **Password Security** – Passwords hashed using **bcrypt**.  
- **Session Management** – Persistent login even after refreshing the page.  

### 2️⃣ Menu Display & Filtering
- **Dynamic Menu** – Menu items fetched from the backend dynamically.  
- **Category Filtering** – Filter menu by categories: *Appetizers*, *Main Course*, *Desserts*, etc.  

### 3️⃣ Add to Cart Functionality
- **Seamless Shopping** – Add, remove, and adjust item quantities in the cart.  
- **Cart Persistence** – Cart state saved across sessions.  

### 4️⃣ Admin & User Pages
- **Admin Dashboard** – Manage menu items, view orders, and handle user queries.  
- **User Dashboard** – View order history & manage account details.  

---

## 🛠️ Technologies Used

### Frontend
- **React.js** – Component-based UI with React Hooks.  
- **CSS/SCSS** – Responsive design with styled-components & custom CSS.  

### Backend
- **Node.js & Express.js** – RESTful API, request handling, routing.  
- **MongoDB** – NoSQL database for storing users, menu items, and orders.  
- **JWT** – Secure authentication and authorization.  

### Tools & Libraries
- **Axios** – For HTTP requests.  
- **Mongoose** – MongoDB object modeling.  
- **bcrypt** – Secure password hashing.
